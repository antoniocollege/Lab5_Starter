1. A unit test looks at a single part of your code to ensure it works, but cannot test how components interact with each other on a larger level. A unit test would not really work for a message feature, as there would be multiple components: for example, both the sender and recipient would need to have accounts, and it would need a way to both read the first user's input, send it, and display it on the other user's phone.
